# BankingApp Coaching Flow

Use this folder as the learner checklist during coaching conversations.

For every issue:

1. Read the issue goal and checkpoint.
2. Write or explain your prediction before coding.
3. Implement the smallest learner-owned change.
4. Run the listed proof command or walkthrough.
5. Bring the code, output, and questions to review.
6. Do not start the next issue until the acceptance evidence is clear.

The assistant may explain concepts, inspect errors, ask questions, and review attempts. The learner writes and explains the banking implementation.
