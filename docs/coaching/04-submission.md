# 04 - Submission

## BA-20 - Regression walkthrough

- Do: freeze optional features and verify the complete local app.
- Checkpoint: which claims are proved by tests, screenshots, or neither?
- Proof: build/tests, happy/rejected/denied flows, and honest limitation list.

## BA-21 - README and technical explanation

- Do: document actual setup, architecture, verified features, and limitations.
- Checkpoint: can you explain a rule change and its affected tests?
- Proof: fresh run instructions work and match the code.

## BA-22 - Screenshots and PDF

- Do: capture consistent synthetic-data screenshots and assemble the submission PDF.
- Checkpoint: what does each image prove?
- Proof: readable captions, rendered/visually inspected PDF; final upload remains a learner action.
